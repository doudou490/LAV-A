# Lavéa v9 — Professional Algeria Edition

## الهدف
نسخة أكثر احترافية لمتجر Lavéa، مناسبة للـDemo والبيع للعميل، مع تجهيز للانتقال لاحقًا إلى قاعدة بيانات وتخزين دائم.

## أهم الإضافات
- لوحة Admin عربية RTL.
- تغيير كلمة مرور Admin من داخل اللوحة.
- جلسات دخول مؤقتة مع انتهاء تلقائي.
- حماية من محاولات تسجيل الدخول المتكررة.
- PBKDF2 لتخزين كلمة المرور بدل تخزينها كنص.
- Security Headers.
- إدارة المنتجات والأسعار والمخزون والصفحات.
- رفع صور من جهازك مباشرة.
- Product Page وLanding Page لكل منتج.
- إدارة توصيل المنزل/المكتب حسب الولاية.
- إدارة الطلبات وحالاتها.
- Meta Pixel + TikTok Pixel + Google Analytics IDs.
- إعدادات هوية المتجر: المدينة، العنوان، الهاتف، WhatsApp، الشبكات الاجتماعية.
- Backup JSON للمنتجات والطلبات والإعدادات.
- تصميم RTL متجاوب مع الهاتف.
- مناسب للسوق الجزائري: COD، الولايات، منزل/مكتب، الدينار الجزائري.

## تشغيل محلي
1. ثبّت Node.js 18+.
2. اضغط START_WINDOWS.bat.
3. افتح http://localhost:3000
4. لوحة الإدارة: http://localhost:3000/admin
5. كلمة المرور الأولى: Lavea@2026
6. بعد الدخول غيّر كلمة المرور من 🔐 الأمان.

## مهم قبل البيع الحقيقي
هذه النسخة Zero DZD ممتازة للعرض والتجربة. للمتجر الإنتاجي الذي سيستقبل طلبات حقيقية، يُفضّل لاحقًا:
- PostgreSQL/Supabase أو قاعدة بيانات مُدارة.
- تخزين صور دائم مثل S3-compatible storage.
- Domain.
- HTTPS.
- Backup تلقائي.
- Server-side Events API لـ Meta/TikTok إذا احتاج العميل Attribution أقوى.

## نشر مجاني مبدئي
ارفع المشروع إلى GitHub ثم اربطه بخدمة Node مثل Render. GitHub يحفظ الكود، بينما Render يشغل الـbackend.
