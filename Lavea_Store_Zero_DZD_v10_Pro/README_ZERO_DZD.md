# Lavéa — تشغيل مجاني (0 دج) + نشر للعميل

## الهدف
هذه النسخة جاهزة للتجربة والنشر على Render Free. GitHub يُستخدم لحفظ الكود، وRender يشغّل التطبيق Node.js.

## تشغيل على Windows بدون برمجة
1. ثبّت Node.js 18+ إذا لم يكن موجودًا.
2. فك الضغط عن المجلد.
3. اضغط مرتين على `START_WINDOWS.bat`.
4. افتح `http://localhost:3000`.
5. لوحة الإدارة: `http://localhost:3000/admin`.
6. كلمة المرور الافتراضية: `Lavea@2026`.

## النشر المجاني
- ارفع مجلد `Lavea_Store` إلى مستودع GitHub عام.
- في Render: New → Web Service → اختر المستودع.
- Build Command: `npm install`
- Start Command: `npm start`
- Plan: `Free`
- أضف Environment Variable باسم `ADMIN_PASSWORD` وضع كلمة مرور جديدة.

## مهم جدًا قبل البيع الحقيقي
هذه النسخة تستخدم ملف JSON محليًا للبيانات وملفات محلية للصور. على Render Free، نظام الملفات مؤقت؛ لذلك الصور والتعديلات المحلية قد تضيع عند إعادة التشغيل أو إعادة النشر أو السكون. هذه النسخة ممتازة للعرض، التجربة، وإعطاء العميل Demo.

لنسخة Production حقيقية لاحقًا، ننقل البيانات إلى قاعدة بيانات وخدمة تخزين دائمة ثم نضيف الدومين.

## Pixels
من لوحة الإدارة أدخل IDs الخاصة بـ Meta Pixel وTikTok Pixel وGoogle Analytics. لا تضع Access Token أو Secret داخل الواجهة.

## الروابط
- المتجر: `/`
- الإدارة: `/admin`
- صفحة المنتج: `/?product=slug`
- Landing Page: `/?landing=slug`


## 🔐 تغيير كلمة مرور الإدارة
بعد تسجيل الدخول إلى لوحة الإدارة:
1. افتح **🔐 الأمان**.
2. اكتب كلمة المرور الحالية.
3. اكتب كلمة المرور الجديدة (8 أحرف على الأقل).
4. أكد كلمة المرور واضغط **تغيير كلمة المرور**.
5. سيتم تسجيل الخروج تلقائيًا، ثم تدخل بالكلمة الجديدة.

كلمة المرور الافتراضية لأول تشغيل محلي: `Lavea@2026`.
